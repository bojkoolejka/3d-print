3D ЗАКАЗЫ — версия 1.8.1 DARK PREMIUM

3D Заказы — PWA v1.3

Обновления:
- Фото детали: до 3 фотографий, показываются в заказе и миниатюрой в списке.
- Напоминание: добавлен вариант «за 1 день».
- После сохранения заказа приложение сразу формирует событие календаря. iOS требует подтвердить добавление события — PWA не может записать его в системный календарь полностью без подтверждения пользователя.
- Убрана нижняя вкладка «Ещё».
- Склад, резервные копии и настройки перенесены в кнопку «…» вверху.
- Добавлена настройка стоимости 1 кВт·ч.
- Электричество заказа считается автоматически: тариф × мощность принтера (кВт) × время печати.
- Версия: 1.3.

Обновление GitHub Pages:
1. Загрузите все файлы поверх старых в корень репозитория.
2. Дождитесь зеленой галочки Pages/Actions.
3. Откройте сайт в Safari. При необходимости удалите старую иконку PWA и добавьте сайт на экран «Домой» повторно.


ВЕРСИЯ 1.4
- В карточке заказа есть кнопка «Позвонить»: запускает звонок на iPhone.
- В карточке заказа есть кнопка «Календарь»: создаёт событие как в приложении для холодильников.
- Напоминание можно выбрать до 1 дня до срока.


ВЕРСИЯ 1.7
- На главном экране: В работе / Ждут оплаты / Завершённые.
- Статус «Готов» считается как «Ждут оплаты».
- Статус «Завершён» переносит заказ в «Завершённые».
- Добавлена вкладка «Клиенты» с историей всех заказов клиента.


НОВОЕ В 1.8:
- Полная тёмная premium-тема.
- Новый голосовой ввод с автоматическим разбором по полям: клиент, телефон, деталь, количество, материал, цвет, расход пластика, цена и срок.
- Если Web Speech API недоступен в PWA на iPhone, приложение откроет поле, куда можно продиктовать текст системной диктовкой iPhone, после чего нажать «Разобрать по полям».


Версия 1.8.1: база 1.8 сохранена без изменений. Изменён только экран «Заказы»: крупные карточки с фото, статусом, клиентом, материалом, сроком и ценой.


Версия 1.8.2: исправлен голосовой ввод. Окно записи больше не закрывает форму заказа; распознанные данные автоматически распределяются по полям клиента, изделия, количества, материала, цвета, расхода пластика, цены, оплаты, времени печати и срока.
