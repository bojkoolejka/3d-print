3D ЗАКАЗЫ — PWA ДЛЯ IPHONE

Что уже есть:
- Заказы и статусы
- Клиенты, телефоны, описание детали, материал, цвет, количество
- Цена заказа
- Стоимость катушки и вес катушки
- Расход пластика в граммах
- Автоматический расчёт стоимости потраченного пластика
- Дополнительные расходы: электричество, расходники, упаковка, доставка, прочее
- Автоматический расчёт общего расхода и чистой прибыли по каждому заказу
- Доходы, расходы и прибыль за текущий месяц
- Общие расходы вне заказа
- Склад материалов
- Резервная копия базы в JSON и восстановление
- Работа офлайн после первого открытия
- Установка на главный экран iPhone

Как считается пластик:
стоимость катушки / вес катушки × потрачено граммов

Пример:
1500 ₽ / 1000 г × 320 г = 480 ₽

Как запустить на Windows для проверки:
1. Распакуйте архив.
2. Откройте папку в Проводнике.
3. В адресной строке Проводника напишите cmd и нажмите Enter.
4. Выполните: python -m http.server 8080
5. Откройте в браузере: http://localhost:8080

Как установить на iPhone через GitHub Pages:
1. Создайте новый публичный репозиторий, например print3d-crm.
2. Загрузите ВСЕ файлы из этой папки в корень репозитория.
3. Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /(root).
6. Сохраните и подождите несколько минут.
7. GitHub выдаст HTTPS-ссылку вида:
   https://ВАШ_ЛОГИН.github.io/print3d-crm/
8. Откройте именно эту ссылку на iPhone в Safari.
9. Поделиться -> На экран «Домой» -> Добавить.

Важно:
Основные данные хранятся локально на iPhone в Safari/PWA.
Периодически делайте резервную копию через «Ещё» -> «Сделать резервную копию».
